Home Assistant Voice Preview Edition

Open, local and private voice for Home Assistant

  • ESP32-S3
  • XMOS XU316
  • USB-C

Home Assistant Voice Preview Edition is the voice assistant built for Home Assistant: dual microphones and an XMOS audio chip hear you in most environments, a multicolour LED ring and rotary dial give feedback and control, and a physical switch cuts power to the microphones. Run voice fully locally, or offload speech processing to the privacy-first Home Assistant Cloud. Install the latest signed firmware, try the beta, or pick an earlier release to roll back.

This browser can’t reach USB serial devices.

Installing firmware needs a desktop browser that supports Web Serial. Open this page on a computer in a browser that offers it, and the install button will appear here.
